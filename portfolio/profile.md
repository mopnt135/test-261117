## 생각하는 공방 블로그

AIPM 수업을 들으며 생각하고 만든 것을 기록하는 복습 노트 블로그입니다.
글은 관리자 한 명이 쓰고, 회원은 글을 읽고 댓글을 달 수 있습니다.
HTML 파일 하나와 Supabase 로 만들었고, GitHub Pages 에 올려 비용 없이 운영합니다.
기획, 화면 설계, 테스트를 직접 했고 코드는 AI 코딩 도구와 함께 썼습니다.

## AI 도우미

글을 올리면 AI 가 독자용 3줄 요약과 관리자용 제목 후보, 태그, SNS 홍보 문구를 미리 만들어 둡니다.
독자가 글을 볼 때는 AI 를 부르지 않아서 비용이 들지 않고, AI 키가 화면에 드러나지 않습니다.
하루 두 번 GitHub Actions 가 자동으로 실행합니다.

## 쓴 도구

HTML, CSS, JavaScript, Supabase, GitHub Pages, GitHub Actions, Google Analytics 4, Claude API, Playwright 를 썼습니다.
