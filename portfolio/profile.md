# 포트폴리오 자료

## 자기소개

안녕하세요! PM을 꿈꾸는 생각하는 공방입니다!

## PM 이 되고 싶은 이유

저는 아이디어를 떠올리는 순간도 즐겁지만, 그 아이디어가 실제로 누군가에게 쓰이는 모습을 볼 때 가장 큰 보람을 느낍니다.
그래서 생각에서 멈추지 않고 기획부터 출시, 운영까지 전 과정을 이어가는 PM 을 목표로 하고 있습니다.
이 블로그에는 그 과정에서 직접 만들고, 부딪히고, 배운 것들을 기록합니다.

## 생각하는 공방 블로그

AIPM 수업을 들으며 생각하고 만든 것을 기록하는 복습 노트 블로그입니다.
글은 관리자 한 명이 쓰고, 회원은 글을 읽고 댓글을 달 수 있습니다.
HTML 파일 하나와 Supabase 로 만들었고, GitHub Pages 에 올려 비용 없이 운영합니다.
기획, 화면 설계, 테스트를 직접 했고 코드는 AI 코딩 도구와 함께 썼습니다.

## AI 도우미

글을 올리면 AI 가 독자용 3줄 요약과 관리자용 제목 후보, 태그, SNS 홍보 문구를 미리 만들어 둡니다.
독자가 글을 볼 때는 AI 를 부르지 않아서 비용이 들지 않고, AI 키가 화면에 드러나지 않습니다.
하루 두 번 GitHub Actions 가 자동으로 실행합니다.

## 블로그 기능

블로그 이름은 생각하는 공방이고, 영어 이름은 THINK & MAKE 입니다.
"생각하는 공방" 은 생각(기획)과 공방(직접 만들기)을 한 이름에 담아 지었습니다.
로고는 전구와 톱니바퀴 그림입니다.
휴대폰과 컴퓨터에서 모두 볼 수 있습니다.
기기를 다크 모드로 쓰면 블로그도 어두운 색으로 바뀝니다.
위쪽 검색 칸에 낱말을 넣으면 글을 찾을 수 있습니다.
이메일과 비밀번호로 회원가입하면 바로 댓글을 달 수 있습니다.
글 주소를 카카오톡이나 SNS 에 공유하면 제목과 썸네일 미리보기가 나옵니다.
오른쪽 아래 포트폴리오 안내 챗봇은 미리 만든 답으로 블로그와 포트폴리오에 관한 질문에 답합니다.

## 쓴 도구

HTML, CSS, JavaScript, Supabase, GitHub Pages, GitHub Actions, Google Analytics 4, Claude API, Playwright 를 썼습니다.
