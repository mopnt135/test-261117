## 1. 사용자와 대화하는 규칙

- 답을 시작할 때 "26.10.31에 업데이트한 클로드 지침에 따라 답변합니다"라고 먼저 말한다.
  지침과 부딪히는 점이 있으면 "사전지침이 있었으나 아래와 같은 상충지점이 있습니다."라고 알리고 검토를 요청한다.
- 한국어, 초보자 눈높이(초등학생도 이해할 만큼). 전문용어는 처음에 한 줄로 풀어 쓴다.
- 칭찬하지 않는다. 빈 곳과 위험을 먼저, 비판적으로 말한다.
- 결론 먼저, 그다음 근거와 순서를 짧은 글머리로.
- 시간은 KST, 돈은 원화.
- 확실하지 않은 수치, 날짜, 최신 정보는 [확인 필요]로 표시한다. 6개월 넘은 지식이면 "웹검색을 할까요?"라고 묻는다.
- 요구가 모호하면 바로 만들지 말고 핵심 질문 3~5개를 먼저 묻는다.

## 2. 과제 개요

- 목적: 개인 학습 과제. 블로그에 AI 기능을 붙여 관리자(사용자)와 독자 둘 다의 워크플로우를 자동화한다. 출시, 운영, 마케팅까지 고려한다.
- 예산: 0원.
- 작업 시간: 2026-11-24 ~ 11-25, 총 16시간 예상.
- 제출물: 기획 문서, 작동하는 사이트 링크, 코드 저장소 링크.

## 3. 정해진 결정

| 결정 | 내용 |
| --- | --- |
| A안 | 기존 GitHub Actions(seo-pages.yml)에 AI 단계를 끼운다. 글마다 AI 결과를 미리 만들어 파일로 저장하고, 독자는 저장된 결과만 본다. 독자가 볼 때 AI 를 부르지 않아 0원 |

| AI 키 | 사용자가 나중에 무료 키를 직접 구한다. 그전에는 시연용 가짜 AI(mode: mock)로 돈다. 키는 GitHub Secrets `AI_API_KEY` 에만 넣는다 |
| AI 제공사 | 코드 기본값은 Gemini API. 무료 조건과 모델 이름은 [확인 필요]. Variables `AI_MODEL` 로 바꾼다 |
| 관리자 화면 | index.html 은 고치지 않고, 따로 만든 `ai/index.html` 보고서로 본다(noindex, 공개 저장소라 누구나 볼 수 있음) |

## 5. 남은 일 (우선순위 순)

1. **OpenWeatherMap 키 폐기.** 2026-11-23 에 커밋 기록에서 지웠다(`1fbbd3b` 부터 11개 커밋 번호가 바뀜). 남은 것은 사용자가 OpenWeatherMap 사이트에서 키를 끄는 일.
   - 먼저 사용자가 OpenWeatherMap 사이트에서 키를 끈다. 이것이 진짜 해결이다.
   - 사용자가 원하면 커밋 기록에서도 지운다: 새로 clone → `git filter-repo --replace-text`(키 → `OPENWEATHER_KEY_REMOVED`) → 기록 전체에 키가 없는지 확인 → **사용자 확인을 받은 뒤** `git push --force origin main`.
   - 키 값은 화면, 대화, 커밋 메시지에 절대 출력하지 않는다.
   - 부작용: `1fbbd3b` 이후 커밋 번호가 바뀌어 docs/TASKS.md 표의 번호가 틀어진다. 다시 맞춘다. GitHub Actions 가 도는 06:17, 18:17 KST 근처는 피한다.
2. Settings > Actions > General 에서 "Read and write permissions" 켜기(사용자), Actions 탭에서 수동 실행, 배포 확인:
   `p/demo-1/` 에 요약 상자, `ai/` 에 보고서.
3. 사용자가 무료 키를 구하면 Secrets `AI_API_KEY` 등록 → 진짜 AI 결과 1건 이상 만들기. 무료 등급의 학습 데이터 사용 조건 [확인 필요].
4. GA4 맞춤 정의에 `has_ai_summary` 등록.
5. 마케팅: AI 가 만든 SNS 문구로 실제 1회 게시. 기존 UTM 규칙(docs/ANALYTICS.md) 사용.
6. 기획 문서 작성(개인 프로젝트용 틀: 한 줄 요약 / 왜 / 시간과 실력 / MVP / 하지 않을 것 / 위험과 그만둘 기준 / 일정). 실제 결과와 숫자를 넣어 11-25 에 쓴다.

## 6. 알려진 약점 (기획 문서에 정직하게 적을 것)

- 가짜 AI 는 본문 앞 세 문장을 요약으로 쓰는 수준이다. 진짜 AI 결과가 최소 1건 있어야 설득력이 있다.
- 공개글만 다루므로 나만보기 초안 단계에서는 AI 추천이 없다.
- 시연용 글도 sitemap 에 들어가 검색엔진이 수집할 수 있다.
- 관리자 보고서는 주소를 알면 누구나 본다.
