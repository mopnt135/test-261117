# 삼색펜 제품 요구사항 (PRD)

기준일: 2026-11-17 (KST)
원본 문서: 사용자 스토리 문서(Claude Docs)와 같은 내용을 에이전트가 읽기 쉽게 옮긴 것입니다. 둘이 다르면 이 파일을 먼저 고치고 사람에게 알립니다.

## 1. 한 줄 요약

AIPM 수업을 복습하는 블로그. **관리자만 글을 쓰고, 회원은 읽고 댓글을 단다.**

## 2. 사용자와 권한

| 할 수 있는 일 | 방문자 | 회원 | 경고 받은 회원 | 추방된 회원 | 관리자 |
| --- | --- | --- | --- | --- | --- |
| 공개글 읽기 | O | O | O | O | O |
| 나만보기(초안) 글 읽기 | X | X | X | X | O |
| 댓글 쓰기 | X | O | O | X | O |
| 내 댓글 고치기 | X | O | O | X | O |
| 내 댓글 지우기 | X | O | O | O | O |
| 남의 댓글 지우기 | X | X | X | X | O |
| 글 쓰기, 고치기, 지우기 | X | X | X | X | O |
| 파일 첨부 | X | X | X | X | O |
| 회원 경고, 추방, 되돌림 | X | X | X | X | O |

- 가입하면 바로 **회원**이 된다. 승인 절차는 없다.
- 관리자는 **1명**. 관리자 지정은 Supabase SQL Editor 에서만 한다.
- 댓글 작성자 이름은 **이메일 앞 3글자 + \*\*\*** 로 보인다. 예: kim\*\*\*

## 3. 사용자 스토리

형식: 관리자로서 나는 ○○하고 싶다. 그래야 ○○할 수 있다.
상태: 됨 / 일부 됨 / 안 됨

### US-1 관리자가 로그인한다 · 됨
- [x] 첫 화면 바로가기, 메뉴, 맨 아래 링크에서 관리자 로그인 화면으로 간다.
- [x] 관리자면 회원 관리 화면으로 바로 이동한다.
- [x] 관리자가 아니면 "관리자 계정이 아닙니다" 안내가 나온다.
- [x] 비밀번호가 틀리면 어느 쪽이 틀렸는지 알려주지 않는다.
- [x] 관리자인지는 서버 규칙으로 확인한다.

### US-2 관리자가 글과 공지를 작성한다 · 일부 됨
- [x] 글쓰기 메뉴와 버튼은 관리자에게만 보인다.
- [x] 회원이 글쓰기 주소로 오면 "삼색펜의 글은 관리자만 씁니다" 안내가 나온다.
- [x] 글은 공개 또는 나만보기(관리자 초안)로 올린다.
- [x] 관리자는 모든 글을 고치고 지운다. 삭제는 두 번 눌러야 한다.
- [x] 회원이 글을 저장하려 하면 서버가 거절한다.
- [ ] 글쓰기 화면에서 "공지로 올리기"를 고를 수 있다. **지금은 공지가 `index.html` 에 고정되어 있다.**
- [x] 글에 JPG, PNG, GIF, PDF 파일을 5개까지 첨부한다. 파일당 10MB.

### US-3 관리자가 불필요한 댓글을 삭제한다 · 일부 됨
- [x] 모든 댓글 옆에 "관리자 삭제" 버튼, 두 번 눌러야 지워진다.
- [x] 회원은 내 댓글만 고치고 지운다.
- [x] 작성자 이름은 서버가 정하고 가려서 보여준다.
- [ ] 삭제할 때 운영 기준 번호를 사유로 고른다.
- [ ] 누가 언제 왜 지웠는지 관리 기록에 남는다.

### US-4 관리자가 질 나쁜 유저에게 경고를 준다 · 일부 됨
- [x] 회원 줄에 경고 버튼과 경고 횟수(예: 2/3)가 보인다.
- [x] 경고 3회면 서버가 자동으로 추방한다. 세 번째 경고는 두 번 눌러야 한다.
- [ ] 경고 사유를 적는다.
- [ ] 경고 받은 회원은 다음 로그인 때 사유와 남은 횟수를 본다. 이메일은 보내지 않는다.
- [ ] 잘못 준 경고를 취소한다.

### US-5 관리자가 질 나쁜 유저를 추방한다 · 일부 됨
- [x] 추방은 두 번 눌러야 한다.
- [x] 추방된 회원은 글은 읽지만 댓글을 쓰거나 고칠 수 없다.
- [x] 추방된 회원의 댓글은 다른 방문자에게 숨겨지고 관리자에게는 보인다.
- [x] 관리자는 추방될 수 없다.
- [x] 추방을 되돌리면 경고 0회 회원이 되고 댓글이 다시 보인다.
- [ ] 추방 사유를 적고, 추방된 회원이 로그인하면 사유를 본다.
- [ ] 추방된 이메일로 다시 가입할 수 없다.

### US-6 관리자가 로그아웃한다 · 됨
- [x] 모든 화면 위쪽에 로그아웃 버튼이 있다.
- [x] 로그아웃하면 첫 화면으로 가고 관리 버튼이 사라진다.
- [ ] 뒤로 가기를 눌러도 관리 화면 내용이 다시 보이지 않는지 실제 Supabase 로 확인한다.

## 4. 결정 사항

| 질문 | 결정 |
| --- | --- |
| 누가 글을 쓰나 | 관리자만 |
| 누가 댓글을 다나 | 로그인한 회원. 가입하면 바로 |
| 몇 번 경고면 추방 | 3회, 자동 |
| 추방된 회원의 댓글 | 모두 숨김. 되돌리면 다시 보임 |
| 경고와 추방 알림 | 블로그 화면에서만. 이메일 없음 |
| 관리자 수 | 1명 |
| 첨부 파일 | JPG, PNG, GIF, PDF. 파일당 10MB, 글당 5개 |
| 나만보기 | 관리자 초안 용도로만 |
| 운영 기준 | "삼색펜 운영 기준" 공지 (`NOTICE_RULES`) |
| **지운 글과 댓글 복구** | **다시 정해야 함.** 지금은 바로 지워짐 |

## 5. 운영 기준 요약

- 불필요한 댓글 5가지: 광고와 홍보, 같은 내용 반복, 출처 없이 옮김, 남의 개인정보, 의미 없는 글자
- 질 나쁜 이용자 5가지: 욕설과 비하, 차별, 불필요한 댓글 반복, 경고 뒤 되풀이, 다른 사람 사칭과 여러 계정
- 조치 순서: 댓글 삭제 → 경고 → 3회면 자동 추방

## 6. 범위 밖

- 댓글 첨부 파일
- 이메일 알림
- 여러 명의 관리자
- 글 서식(굵게, 표 등). 지금 본문은 글자만 받는다.
